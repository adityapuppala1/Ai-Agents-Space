# Roadmap status

Status of every numbered section, bullet, and table row of [PRODUCT_ROADMAP.md](../PRODUCT_ROADMAP.md) against the code in this repository. Reviewed on 9 September 2026 against the verification run of the same day: `npm test` 195/195, `npm run build` OK, `npx playwright test` 9/9, real server boot on Windows 11 with Claude Code 2.1.258, Codex 0.152.1, Copilot 1.0.80 detected.

**Status values**

- **Done**: code and tests exist, and the behaviour was exercised (unit/integration/e2e or a manual check named in Evidence).
- **Partial**: some of the item exists; Notes say what is missing.
- **Deferred**: not built; Notes give the reason.
- **Not applicable in software**: the roadmap item is a research note, a process rule, or marketing copy rather than a feature.

**Provider claims** follow the capability matrix in [CONNECTIONS.md](CONNECTIONS.md): Claude Code and Copilot managed runs were verified on this machine on 2026-09-09; the Codex `exec --json` stream format was verified but the end-to-end run hit the account usage limit; `cursor-agent` is not installed here (only the Cursor IDE launcher), and although a `gemini` 0.59.0 binary is on PATH no Gemini run or session has been verified, so those adapters stay `experimental`/`unknown`.

**Abbreviations**: `core/` = `packages/core/src/`, `server/` = `packages/server/src/`, `web/` = `apps/web/src/`.
